# Фитнес-агент

Учебный итоговый проект. Веб-приложение на Python + Streamlit: пользователь
заполняет короткую анкету, модель составляет ему программу тренировок
и план питания.

Автор — новичок в программировании. Код должен быть понятен новичку.

## Стек

- Python 3.10+
- Streamlit — интерфейс
- google-genai — официальная библиотека Google для Gemini API
  (старая `google-generativeai` устарела, её не использовать)

Модель задаётся одной константой `MODEL` в начале `agent/llm.py`.
Сейчас это `gemini-3.5-flash-lite` — бесплатный тариф Google AI Studio.
Чтобы сменить модель, меняется только эта строка.

На ошибку 5xx (перегрузка модели) `llm.py` делает 3 попытки с паузой
в 5 секунд — это нормальное поведение бесплатного тарифа, не убирать.

## Структура

```
app.py                      — интерфейс: анкета, ключ в боковой панели, вывод плана
.streamlit/config.toml      — цвета темы и настройки запуска
.env.example                — образец настроек (DEMO_MODE), сам .env в git не идёт
agent/llm.py                — единственное место, где вызывается модель
agent/pipeline.py           — цепочка шагов: безопасность → тренировки → питание
agent/prompts/safety.md     — промпт шага 1 (проверка анкеты)
agent/prompts/workout.md    — промпт шага 2 (программа тренировок)
agent/prompts/nutrition.md  — промпт шага 3 (план питания)
examples/sample_profile.json— анкета-пример: её подставляет кнопка «Заполнить пример»
examples/demo_responses/    — настоящие ответы модели на эту анкету, для демо-режима
scripts/zapisat_demo.py     — разовый прогон пайплайна, записывает demo_responses
screenshots/                — скриншоты приложения
requirements.txt            — список библиотек
```

## Как работает генерация

1. `app.py` собирает ответы в словарь и передаёт его в `sobrat_plan()`.
2. Шаг 1 — `proverit_bezopasnost()`: модель возвращает JSON со статусом
   `ok` / `caution` / `stop`. Формат гарантирован схемой `SHEMA_BEZOPASNOSTI`,
   поэтому ответ разбирается обычным `json.loads()`.
3. При статусе `stop` остальные шаги не запускаются — вместо плана совет идти к врачу.
4. Шаг 2 — `sostavit_trenirovki()`: программа приходит текстом в Markdown.
5. Шаг 3 — `sostavit_pitanie()`: план питания, тоже текстом в Markdown.
6. Ошибки сети, ключа и лимитов превращаются в `OshibkaAPI` с понятным текстом,
   `app.py` ловит её и показывает пользователю. Исчерпанный бесплатный лимит
   (код 429) — отдельное сообщение «Лимит бесплатных запросов исчерпан,
   попробуйте через минуту».

## Оформление

- Стиль: тёмная шапка + белая карточка формы на светло-сером фоне, акцент — зелёный `#0E7C5A`.
- Цвета темы живут в `.streamlit/config.toml`, остальной стиль — один блок CSS
  в переменной `STILI` в начале `app.py`. Новых css-файлов не заводим.
- Меняя вёрстку, проверяй приложение в браузере: Streamlit часто ужимает
  блоки по содержимому, селекторы вида `[data-testid="..."]` подсматривай в разметке.

## Как устроен вывод

- Streamlit перезапускает скрипт при любом действии на странице, включая
  изменение размера окна. Поэтому ответы анкеты, готовый план и текст ошибки
  лежат в `st.session_state` (`otvety`, `plan`, `oshibka`), а блок вывода
  читает их оттуда. Без этого план пропадал после первого же перезапуска.
- Ключ `anketa` в `st.session_state` занят формой `st.form("anketa")`
  и доступен только для чтения — свои данные туда класть нельзя.
- Тренировки и питание выводятся на вкладках `st.tabs`, под ними дисклеймер
  (константа `DISKLEYMER`) и кнопка «Скачать план». Файл для скачивания
  собирает `sobrat_fayl_plana()` — один текст Markdown из анкеты,
  тренировок, питания и того же дисклеймера.
- Поля анкеты заданы словарём `POLYA`: ключ виджета → подпись, под которой
  ответ уходит модели. Через него же работает кнопка «Заполнить пример».
  Новое поле добавляется в `POLYA`, в форму и в `sample_profile.json`.
- Значение виджета Streamlit разрешает менять только до его создания.
  Поэтому «Заполнить пример» поднимает флаг `zapolnit_primer` и вызывает
  `st.rerun()`, а подстановка идёт в блоке перед формой. Прямая запись
  в `st.session_state` после создания виджета падает с ошибкой.
- Ошибки показываются жёлтым `st.warning` двумя частями: что случилось
  и что делать. Текст и совет лежат в `OshibkaAPI` (аргументы конструктора),
  в `session_state.oshibka` хранится пара из них. Красный `st.error`
  оставлен только для статуса `stop` — там это по делу.

## Правила работы с кодом

- Код простой и прямолинейный: без классов, декораторов и абстракций,
  если задачу можно решить обычной функцией.
- Все комментарии и текст в интерфейсе — на русском языке.
- Никаких лишних файлов. Не создавать модули, конфиги, тесты и утилиты,
  о которых не просили. Если нужен новый файл — сначала спросить.
- Одна задача — одно изменение. Не рефакторить код «попутно».
- API-ключ пользователь вводит в боковой панели (поле с `type="password"`).
  Ключ не сохраняется ни в код, ни в файлы, ни в переменные окружения,
  в том числе в `.env`. Никогда не писать ключ в код и не логировать его.
- Демо-режим включается, если ключа нет или в `.env` стоит `DEMO_MODE=true`.
  В нём приложение показывает сохранённые ответы из `examples/demo_responses/`
  и обязано честно писать, что это заранее записанный пример для анкеты
  из `sample_profile.json`, а не ответ модели на введённые данные.
  Выдуманный план вместо настоящего не показывать никогда.
- Файлы в `examples/demo_responses/` — настоящие ответы модели, записанные
  прогоном пайплайна на `sample_profile.json`. Руками их не сочинять:
  если промпты заметно поменялись, перезаписать новым прогоном.
- Все обращения к модели — только через `agent/llm.py`. В остальных файлах
  не должно быть ни импорта `google.genai`, ни названия модели.
  Промпты — только файлами в `agent/prompts/`, не строками в коде.
- Не коммитить и не пушить без явной просьбы.

## Запуск

```bash
streamlit run app.py
```

Streamlit перезапускает только `app.py`. Файлы из `agent/` он держит
в памяти такими, какими импортировал при старте, поэтому после правок
в `agent/*.py` сервер нужно остановить (`Ctrl + C`) и запустить заново —
иначе страница падает на старом коде, например с `ImportError`
на только что добавленной функции.
